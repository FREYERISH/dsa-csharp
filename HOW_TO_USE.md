# Extra Warm-up Pack (12 problems)

Copy the `Solutions` and `Solutions.Tests` folders into your `dsa-csharp` folder and let them merge.
Nothing you've already written is replaced: these are all new files in `Warmup/`.

Then run `dotnet build`. Same workflow as before: delete the `throw` line, solve, run the problem's test, submit on LeetCode, commit.
